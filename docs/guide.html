Lynux

A live Arch Linux toolbox for fixing, installing and looking after computers with AI coding agents.

English | 中文

Get online

Connect to Wi-Fi or Ethernet from the system tray. Then open the Lynux Welcome window and pick an AI tool: Codex, Claude Code, Kimi Code, DeepSeek Harness or OpenCode. Each opens as root in its own Konsole window, starting in /workspace. Sign in with your own account or API key. DeepSeek Harness runs dsh web and is used in the browser.

Keep your work

By default everything is gone after you shut down. To keep the AI tools' logins and /workspace, open Encrypted storage in the welcome window and create a password-protected file on a USB drive or disk. Next time, unlock it from the same page. System changes and desktop settings are never saved.

When you lock the storage, Lynux lists any programs still using it and lets you choose which to end. A forgotten password can't be recovered. Encryption isn't a backup: copy the locked container file somewhere safe before switching to a new weekly ISO.

The same steps from a terminal:

sudo lynux-state status
sudo lynux-state create /run/media/live/USB/Lynux/state.luks --size-gib 8 --make-parent
sudo lynux-state unlock /run/media/live/USB/Lynux/state.luks
sudo lynux-state holders
sudo lynux-state lock

Other systems' ISOs

Keep ISOs anywhere. On the Disk images page you can check an ISO's SHA-256 against the download page and mount it read-only. To install another system, mount its ISO and ask an AI tool to walk you through it with that system's own installer. Double-check the target disk before anything is partitioned or written.

lynux-iso inspect '/path/to/distro.iso'
sudo lynux-iso mount '/path/to/distro.iso'
sudo lynux-iso list
sudo lynux-iso unmount MOUNT_ID

Language and input

Lynux starts in English with the clock on UTC. Pick another language at the bottom of the welcome window's sidebar: the window switches right away and the desktop switches after you log out. Fcitx5 has Pinyin, Zhuyin, Cangjie, Quick, Jyutping and Japanese ready. Press Ctrl+Space to switch.

Booting

Ventoy boots normally, without Secure Boot. A signed UEFI image written straight to a drive can boot with Secure Boot after you add the release certificate to your firmware's db. The ARM64 image needs UEFI firmware. Specific boards need their own kernel, device tree and bootloader.

English | 中文

先联网

在系统托盘连上 Wi-Fi 或有线网络，然后在 Lynux 欢迎窗口里选一个 AI 工具：Codex、Claude Code、Kimi Code、DeepSeek Harness 或 OpenCode。每个工具会以 root 身份在单独的 Konsole 窗口里打开，从 /workspace 开始。用你自己的账号或 API Key 登录。DeepSeek Harness 运行的是 dsh web，在浏览器里使用。

保留你的工作

默认关机后一切都会清空。想保留 AI 工具的登录状态和 /workspace，就在欢迎窗口打开加密存储，在 U 盘或硬盘上建一个有密码保护的文件。下次在同一页解锁即可。系统改动和桌面设置不会保存。

锁定时，Lynux 会列出还在使用存储的程序，由你决定结束哪些。忘了密码就找不回来。加密不等于备份：换新的周更 ISO 之前，先把锁定状态下的容器文件复制一份。

也可以在终端里操作：

sudo lynux-state status
sudo lynux-state create /run/media/live/USB/Lynux/state.luks --size-gib 8 --make-parent
sudo lynux-state unlock /run/media/live/USB/Lynux/state.luks
sudo lynux-state holders
sudo lynux-state lock

其他系统的 ISO

ISO 放在哪里都行。在磁盘镜像页可以对照下载页面校验 SHA-256，也可以只读挂载。要装其他系统，挂载它的 ISO，再让 AI 工具带你用那个系统自己的安装程序一步步装。分区或写盘之前，务必再确认一次目标磁盘。

lynux-iso inspect '/路径/发行版.iso'
sudo lynux-iso mount '/路径/发行版.iso'
sudo lynux-iso list
sudo lynux-iso unmount 挂载ID

语言和输入法

Lynux 默认英文界面，时区为 UTC。在欢迎窗口侧边栏底部可以换语言：窗口马上切换，桌面在注销后切换。Fcitx5 已配好拼音、注音、仓颉、速成、粤拼和日语，按 Ctrl+Space 切换。

启动方式

Ventoy 走普通启动，不需要 Secure Boot。直接写盘的签名 UEFI 镜像，把发布证书加进固件的 db 后就能开 Secure Boot 启动。ARM64 镜像需要 UEFI 固件，具体开发板还需要对应的内核、设备树和引导程序。
